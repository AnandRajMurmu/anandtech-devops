# Slack Notification Policy

Slack is an output channel, not a source of curriculum authority.

## Notify on

- Unit approved
- Human decision required
- Three review rounds exhausted
- Section ready for acceptance
- Missing or conflicting SSOT blocks work

Do not notify every drafting step, routine Worker progress, or optional review suggestions.

Each message includes event, repository, section/unit, verdict, PR link, required action, and blocker summary when applicable. Select and test the channel before enabling notifications.
