# Example Units

These files are historical, non-authoritative references copied from the backup repository.

They may demonstrate useful structure, depth, exercises, or formatting, but they are not locked SSOTs and are not automatically quality-approved. Agents must:

- follow the current locked Global and Section SSOTs first;
- use examples only when a specific feature helps the assigned unit;
- never copy obsolete scope, environment assumptions, or technical claims blindly;
- never treat an example as permission to generate a unit.

When an example conflicts with current authority, ignore the example and report the conflict.
