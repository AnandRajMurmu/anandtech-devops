# Journey with AnandTech — DevOps Zero to Production

This is the clean source-of-truth repository for designing and producing the Journey with AnandTech DevOps course.

## Platform

- **ChatGPT Work** acts as Manager and runs the specialist agent roles.
- **GitHub** stores SSOTs, plans, units, reviews, and approvals.
- **Slack** sends notifications only.
- There is no separately hosted agent runtime.

## Start here

1. Read `AGENTS.md`.
2. Follow `workflow/CHATGPT_WORK_SETUP.md`.
3. Review `docs/project_SSOT.md`.
4. Review the draft Section 00 SSOT.
5. Revise it through an SSOT pull request.
6. Merge that PR only when you intend to lock the SSOT.
7. Generate and review one unit at a time.
